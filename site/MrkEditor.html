What changes

You stop guessing where to start.

The screenshots are the product here. Each tool starts from the same idea: measure the file first, then jump back to the exact lines worth reading.

01 / Counts

Start with the value that appears too often.

A log line says many things. MrkEditor counts one field at a time, so the repeated user, status, host or error code rises to the top.

Then click the row to narrow the text to those lines.

02 / Time

The spike is the part worth reading.

After filtering to errors, MrkEditor draws the timeline. A quiet file and a failing file look different before you read a single line.

Drag over a spike, and the editor jumps back to that time window.

03 / CSV

Find the strange column before opening a spreadsheet.

MrkEditor scans every column and shows blanks, distinct values, min/max, sums and averages. It is a quick map of the CSV before you decide what to inspect.

04 / Folders

When one file is not enough, search the folder.

Search results are not a dead list. Click a hit and MrEditor opens that file at that line, with the encoding handled per file.
