# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through GitHub's [Private Vulnerability Reporting](https://github.com/MR-TABATA/MrEditor/security/advisories/new).

Please do not create a public issue for security-related matters.
